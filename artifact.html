Three aesthetic directions for the portfolio OS

Same window, same folder, same five repositories, same sidebar metadata, same dock, same boot screen. The markup underneath all three is byte-for-byte identical, so everything that differs below is treatment, not content.

Direction one · recommended

Modern base, technical detailing

Keep the blur, the radii, and the depth. Make the chrome speak monospace and draw the icons on a grid. Contemporary surface, systems-tool voice.

What it buys

  • The Terminal and the BIOS boot screen stop reading as bolted on. Mono chrome is the same voice the shell already speaks.
  • Cheap to draw. Every icon is strokes on a 24-unit grid, so the whole set is one path map rather than 24 components.
  • Tokens do the work, so four themes across dark and light stay tunable and contrast stays checkable.

What it costs

  • Less immediately charming than retro. It earns attention on detail rather than on nostalgia.
  • Needs discipline: mono belongs to chrome only. The moment it leaks into prose the whole thing reads as a terminal emulator.

Where it shows up

  • Title bars, sidebar metadata, dock counts, the Terminal prompt, and the file-type labels all share one typographic voice.
  • The MDir, MDoc, and 644 gags stop being isolated jokes and start reading as one system.

Direction two · highest charm, highest cost

Full retro

System 7 chrome. Pinstripe title bars, black hairlines, dithered desktop, hard drop shadows, selection by inversion. No translucency anywhere.

What it buys

  • The strongest identity of the three, and the only one nobody will mistake for another portfolio.
  • The BIOS boot screen stops being a joke and becomes the premise the whole site is built on.

What it costs

  • Every bezel, control, scrollbar, and icon is hand-drawn art, and it has to stay consistent across dozens of states.
  • Bitmap chrome resists theming. Four colour themes across dark and light is exactly where this breaks, and the accessibility contract requires AA in all eight.
  • It dates fast, and a faithful System 7 copy reads as pastiche rather than as yours.

Where it shows up

  • Everywhere, which is the problem. This is a whole-site commitment with no partial version.
  • The apps inherit it too: the Résumé viewer, the case study reader, and Mail all need period-correct chrome.

Direction three · where the old site already is

Full glass

Lean all the way into translucency. Heavy backdrop blur, generous radii, soft light, a cyan-to-violet gradient carrying the accent.

What it buys

  • Cheapest of the three to build, and the prettiest at first glance. No new art is needed.
  • It is close enough to the old site that the reskin becomes a refinement rather than a redraw.

What it costs

  • Nothing distinguishes it from every other portfolio using a glass aesthetic. The concept carries all the personality and the surface carries none.
  • It fights the two things that make the concept yours. A soft gradient boot screen is not a POST sequence, and a glass Terminal is a contradiction.

Where it shows up

  • This is where the old site already is, so choosing it is choosing not to change.
  • Heavy backdrop-filter on every window is also the most expensive of the three to composite once several are open.

Next

Pick a direction and the OS name follows from it. A name that fits pinstriped System 7 chrome is not the name that fits a monospace systems tool, which is why 1.2 sits behind this decision rather than beside it. Once it is chosen, the shortlist comes back drawn from the same world, and the boot sequence, the Terminal prompt, System Info, and the MDir and MDoc labels all get written against it.
